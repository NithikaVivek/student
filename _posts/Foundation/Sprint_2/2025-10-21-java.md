## Part I: Java Programming Fundamentals

### Object-Oriented Programming Foundations

Java's power lies in **object-oriented thinking**—modeling real-world entities through code. This paradigm fundamentally changed how I approached problem-solving.

**Classes as Blueprints:**

```java
public class Student {
    // Fields (instance variables)
    private String name;
    private int studentId;
    private double gpa;
    
    // Constructor
    public Student(String name, int studentId, double gpa) {
        this.name = name;
        this.studentId = studentId;
        this.gpa = gpa;
    }
    
    // Methods
    public void displayInfo() {
        System.out.println("Name: " + name);
        System.out.println("ID: " + studentId);
        System.out.println("GPA: " + gpa);
    }
    
    public boolean isHonorsStudent() {
        return gpa >= 3.5;
    }
    
    // Getters and Setters
    public String getName() {
        return name;
    }
    
    public void setGpa(double newGpa) {
        if (newGpa >= 0.0 && newGpa <= 4.0) {
            this.gpa = newGpa;
        }
    }
}
```

**Key Concepts Learned:**

**Encapsulation:** Fields marked `private` prevent direct external access. Public methods provide controlled interfaces. Notice how `setGpa()` validates input before modifying.

**The `this` Keyword:** Distinguishes instance variables from parameters. In the constructor, `this.name = name` assigns the parameter to the instance variable.

**Constructors:** Special methods that initialize new objects, ensuring they start in valid states.

### Collections and Data Structures

**ArrayLists for Dynamic Storage:**

```java
import java.util.ArrayList;

public class Classroom {
    private ArrayList<Student> students;
    
    public Classroom() {
        students = new ArrayList<>();
    }
    
    public void addStudent(Student s) {
        students.add(s);
    }
    
    public void displayAllStudents() {
        for (Student s : students) {
            s.displayInfo();
            System.out.println("---");
        }
    }
    
    public double getAverageGPA() {
        if (students.isEmpty()) return 0.0;
        
        double sum = 0;
        for (Student s : students) {
            sum += s.getGpa();
        }
        return sum / students.size();
    }
}
```

**Inheritance and Polymorphism:**

```java
public class GraduateStudent extends Student {
    private String researchArea;
    
    public GraduateStudent(String name, int id, double gpa, String research) {
        super(name, id, gpa);  // Call parent constructor
        this.researchArea = research;
    }
    
    @Override
    public void displayInfo() {
        super.displayInfo();  // Call parent method
        System.out.println("Research: " + researchArea);
    }
}
```

Key concepts:
- **Extends keyword** creates inheritance relationships
- **Super keyword** accesses parent class methods and constructors
- **@Override** explicitly marks method overriding

## Part II: Automated Color Management System

### The Challenge: Maintaining Design Consistency

Working on a large Jekyll-based project with multiple SCSS files revealed a critical problem: **color values scattered across dozens of files made maintaining consistent design nearly impossible**. Changing a single color required hunting through the entire codebase.

The solution: **an automated Python script that scans all SCSS files, extracts color variables, and generates consolidated color maps**.

### System Architecture


### Color Extraction Logic

```python
def extract_variable_value(self, scss_content, variable_name):
    """
    Extract the value of a specific SCSS variable.
    
    Handles:
    - Standard: $var: value;
    - With !default: $var: value !default;
    - Alternative: $var := value;
    """
    # Remove comments to avoid false matches
    scss_content = re.sub(r'//.*$', '', scss_content, flags=re.MULTILINE)
    scss_content = re.sub(r'/\*.*?\*/', '', scss_content, flags=re.DOTALL)
    
    # Match variable definition
    pattern = rf'{re.escape(variable_name)}\s*:=?\s*([^;]+);'
    matches = re.findall(pattern, scss_content)
    
    if matches:
        value = matches[-1].strip()
        value = re.sub(r'\s*!default\s*$', '', value)
        return value
    
    return None
```

### Color Value Detection

```python
def is_color_value(self, value):
    """
    Determine if a value represents a color.
    
    Checks for:
    - Hex colors (#RGB, #RRGGBB)
    - RGB/RGBA functions
    - HSL/HSLA functions
    - CSS gradients
    - Variable references
    """
    # Hex colors
    if re.match(r'^#[0-9a-fA-F]{3,8}$', value):
        return True
    
    # RGB/RGBA
    if re.match(r'^rgba?\(', value):
        return True
    
    # HSL/HSLA
    if re.match(r'^hsla?\(', value):
        return True
    
    # Gradients
    if 'linear-gradient' in value or 'radial-gradient' in value:
        return True
    
    # Variable references
    if re.match(r'^\$[a-zA-Z_]', value):
        return True
    
    return False
```
