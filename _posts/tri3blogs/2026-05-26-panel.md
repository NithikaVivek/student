# Page 4: Building a Dynamic Panel System

## Learning How Systems Connect

Another major technical challenge involved creating a dynamic panel system that tracked information users entered and updated as they progressed through the onboarding game.

The panel displayed:

* Student information
* Progress
* Points earned
* Level updates

This project expanded my understanding of how systems persist information across experiences.

Before this, much of my coding involved isolated programs. The panel system forced me to think beyond a single page and consider:

**How does information move through an entire system?**

I learned about:

* State management
* Data persistence
* Frontend-backend continuity
* Scalability

Instead of hardcoding every interaction, I had to think more abstractly about creating flexible systems that could adapt as the game expanded.
