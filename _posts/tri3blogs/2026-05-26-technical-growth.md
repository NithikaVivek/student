# Page 1: Technical Growth Reflection — Introduction

## From Coding Assignments to Building Real Systems

At the beginning of this year, I viewed computer science primarily as solving isolated programming problems and completing assignments. While I understood basic coding concepts, I had not yet experienced what it meant to design systems for real users, collaborate on larger technical projects, or think deeply about how technology can improve learning experiences.

Over time, my perspective changed.

Through projects such as building an onboarding game for incoming freshmen, developing dynamic systems, configuring AI tools locally, and collaborating with peers, I learned that technical growth is about much more than learning syntax or writing functional code.

It is about:

* Thinking systematically
* Debugging effectively
* Designing for users
* Collaborating across systems
* Solving problems independently

I began shifting from asking, *“How do I make this code work?”* to asking, *“How do all these systems work together to create a meaningful experience?”*

### Key Takeaway

**Technical growth is not just learning to code—it is learning how to think, collaborate, and build systems for people.**

## Becoming More Than a Programmer

Looking back, I grew significantly both technically and personally.

I became:

* More confident building systems
* More collaborative in team environments
* More reflective about user experience
* More comfortable with technical uncertainty

Most importantly, I changed the way I think.

Instead of only asking whether code works, I now think about:

* How systems interact
* How users experience technology
* How collaboration strengthens outcomes

This year taught me that growth is rarely linear.

It comes through:

* Experimentation
* Mistakes
* Reflection
* Persistence

While there is still much to learn, I now feel more prepared to tackle increasingly complex technical challenges in the future.

### Final Takeaway

**Computer science is not just about coding—it is about solving problems, building systems, and creating meaningful experiences for people.**
