# Page 6: Learning AI Infrastructure & Localhost

## Stepping Outside My Comfort Zone

One of the most technically challenging parts of the trimester involved learning how to run AI systems locally and configure API integrations.

This was completely unfamiliar territory.

I had to:

* Configure API keys
* Troubleshoot localhost issues
* Debug system errors
* Understand how multiple tools connected

Unlike classroom assignments, there was no step-by-step solution.

Many problems required experimentation and persistence.

At first, the process felt overwhelming. But over time, I became more comfortable navigating uncertainty and troubleshooting independently.

This experience strengthened something more important than technical knowledge:

**confidence.**

I became more confident in my ability to learn unfamiliar technologies and solve problems independently.
